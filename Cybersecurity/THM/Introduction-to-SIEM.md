# Introduction to SIEM - THM room

SIEM - Security Information and Event Management system; security solution that a SOC analyst uses in the security operation center

Multiple devices are communicating in a network with each other and, most of the time, with the Internet through a router.

The devices in the network can be called log sources (serving as a trail of all the activities, being very helpful for identifying malicious activities or troubleshooting)

## Log sources:

1. Host-Centric Log Sources - capture events occured within or related to the host (include Windows, Linux, servers, etc)

                            example: a user accessing a file, attempt to authenticate, a process execution activity

2. Network-Centric Log Sources - network-related logs are generated when the hosts communicate with each other or access the internet to visit a website. Example of devices using this type of logs are firewalls, IDS/IPS, routers, etc

                             example of network-centric logs: SSH connection, a file being accessed via FTP, web traffic
